## Entry

> thanhvu261090

## How it works

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) writes the
username to `/output/entry.txt`, after a gate check enforces the
competition gate: UTF-8 text, 1 to 30 characters, not only whitespace,
a single word with no spaces, no padding, no control characters, and
only letters, digits, `-` or `_`.
